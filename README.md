# ieee-vis-tutorial-2026

This repository contains the materials for [Custom widgets for Python notebooks
with anywidget and marimo](https://www.ieeevis.org/year/2026/info/program/tutorials/),
presented by Trevor Manz and Kiran Gadhave at IEEE VIS 2026.

The goal is to explore how interactive JavaScript visualizations can be used in
Python notebooks with [marimo](https://marimo.io) and
[anywidget](https://anywidget.dev).
