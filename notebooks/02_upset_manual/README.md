# UpSet walkthrough

We edit two files: `upset.js` and `notebook.py`. The notebook has a tab for each
step with the idea and the solution.

If you fall behind, `checkpoints/` contains both files as they look after each
step. Open the checkpoint notebook for the step we just finished and carry on
from there.

To see the chart before it becomes a widget, run this from the repository root:

```sh
uv run python -m http.server 8000 --bind 127.0.0.1
```

Open <http://localhost:8000/notebooks/02_upset_manual/page/>.
